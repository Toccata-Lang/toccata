# Master Plan

## Overview
This document outlines the high-level plan for the Toccata project.

## Goal
- Make Toccata be the best language and runtime for web and phone apps backed by a database

## Steps to Achieve the Goal
- Complete the language compiler
  - Define Language Specification
  - Implement Interpreter
    - Implement Parser
  - Semantic Analysis, Dependent Type Checking, etc
  - Code Generation
  - Runtime System
  - Testing and Validation
- Port Electric Clojure to Toccata
- Write tutorials and sample apps
- Make videos
